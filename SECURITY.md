# Segurança

Se encontrares uma vulnerabilidade (por exemplo, na API, nas notificações ou na recolha), **não abras um issue público**.
Usa o [relatório privado de vulnerabilidades do GitHub](https://github.com/tpereira2005/varrendo-a-esquerda/security/advisories/new).

O site não guarda dados pessoais: só as subscrições de notificações (endereço do serviço de push e chaves públicas do
aparelho), que se apagam ao desativar. Os resultados eleitorais são públicos.
